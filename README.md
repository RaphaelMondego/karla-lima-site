# Clínica Dra. Karla Lima | Estética Avançada

Site institucional single-page da Clínica Dra. Karla Lima — harmonização facial, emagrecimento assistido e procedimentos corporais na Vila Formosa, São Paulo.

## Estrutura

```
karla-lima-site/
├── index.html      # conteúdo, SEO e Open Graph (prévia no WhatsApp)
├── css/style.css   # layout mobile-first, cristal 3D em CSS puro, glassmorphism
├── js/main.js      # progresso de scroll, reveal, contadores, menu, partículas
└── README.md
```

Sem frameworks e sem build: é só abrir o `index.html` no navegador.

## Seções

Navbar fixa · Hero com cristal 3D + partículas rose gold · Ticker de procedimentos · Sobre · 12 procedimentos com preços · Galeria · CTA de avaliação gratuita · Diferenciais com contadores · Localização com mapa · Rodapé com aviso legal · Botão flutuante de WhatsApp.

## Publicação (GitHub Pages)

1. Faça push para o branch `main`.
2. No GitHub: **Settings → Pages → Source: Deploy from a branch → `main` → `/ (root)` → Save**.
3. Em 1–2 minutos o site fica disponível em `https://<usuario>.github.io/karla-lima-site/`.
